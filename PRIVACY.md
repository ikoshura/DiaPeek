# DiaPeek — Datenschutzerklärung / Privacy Policy

_Stand / Last updated: 2026-07-01_

## Deutsch

**DiaPeek erhebt, speichert, überträgt und verkauft keine personenbezogenen Daten.**

DiaPeek öffnet Links, die sonst einen neuen Tab öffnen würden, stattdessen in
einer Vorschau („Peek") – als angedocktes In-Page-Overlay oder als eigenes
Fenster –, damit du verlinkte Seiten ansehen kannst, ohne deine aktuelle Seite
zu verlassen.

**Datenverarbeitung**
- Die URL eines angeklickten Links wird ausschließlich verwendet, um diese Seite
  im Peek anzuzeigen. Das geschieht lokal im Browser und wird nicht gespeichert
  oder versendet.
- Die im Peek angezeigte Seite wird direkt von ihrer eigenen Website in deinen
  Browser geladen. DiaPeek leitet ihren Inhalt nicht um, protokolliert ihn nicht
  und liest ihn nicht aus.
- DiaPeek speichert ausschließlich deine Einstellungen (Anzeigemodus und welche
  Klicktypen abgefangen werden) über die Chrome-Speicher-API. Diese
  Einstellungen verlassen deinen Browser nicht – außer über die von dir selbst
  aktivierte Google-Konto-Synchronisierung.
- DiaPeek enthält keine Analyse, kein Tracking und keine Server von Drittanbietern.

**Berechtigungen**
- Host-Zugriff (`<all_urls>`): um Link-Klicks auf beliebigen Seiten abzufangen und
  die Zielseite im Peek einzubetten.
- `declarativeNetRequest`: um die Framing-Header (`X-Frame-Options`/CSP) nur für
  die aktuell gepeekte Seite zu entfernen, damit sie im Peek dargestellt werden kann.
- `tabs` / `tabGroups`: um eine gepeekte Seite in einem echten Tab zu öffnen und
  ihn der aktuellen Tab-Gruppe zuzuordnen.
- `storage`: um deine Einstellungen zu speichern.

DiaPeek verwendet keinen Remote-Code; der gesamte Code ist im Erweiterungspaket
enthalten.

## English

**DiaPeek does not collect, store, transmit, or sell any personal data.**

DiaPeek opens links that would otherwise open a new tab in a preview (“Peek”) —
an in-page overlay or a separate window — so you can view linked pages without
leaving your current page.

**Data handling**
- The URL of a link you activate is used solely to display that page in the Peek.
  This happens locally in your browser and is not stored or transmitted.
- The peeked page is loaded directly from its own website into your browser.
  DiaPeek does not route, log, or read its content.
- DiaPeek only stores your settings (display mode and which click types to
  intercept) using Chrome’s storage API. These settings never leave your browser
  except via your own Google account sync, if you have it enabled.
- DiaPeek contains no analytics, tracking, or third-party servers.

**Permissions**
- Host access (`<all_urls>`): to intercept link clicks on any site and embed the
  target page in the Peek.
- `declarativeNetRequest`: to remove framing headers (`X-Frame-Options`/CSP) only
  for the currently peeked page so it can be displayed in the Peek.
- `tabs` / `tabGroups`: to open a peeked page in a real tab and keep it in the
  current tab group.
- `storage`: to save your settings.

DiaPeek uses no remote code; all code ships inside the extension package.
